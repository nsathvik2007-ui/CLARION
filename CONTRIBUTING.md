# Contributing (architecture-only stage)

1. Read the root README and docs/architecture/architecture-v4-spec.md.
2. Inspect the README in the module directory and its comment-only file stubs.
3. Open a scoped phase branch, declare changed input/output contracts, and add meaningful tests.
4. Use real test outputs; no fabricated benchmarks, trained probabilities, network associations or risk paths.
5. Never commit sensitive datasets, model binaries, licensed GeoIP or unreviewed captures.
6. Submit a PR with evidence, security/privacy review, honest limitations and an exact next phase.
7. No implementation is currently complete. Comment-only files are blueprints, **not runnable modules**.
